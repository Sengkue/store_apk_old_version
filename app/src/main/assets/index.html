ເປີດໄຟລ໌ .APK ຈາກ WhatsApp / File Manager ໂດຍກົງ

ເວລາທ່ານກົດເປີດໄຟລ໌ .apk ຈາກແອັບອື່ນ ທ່ານສາມາດເລືອກເປີດດ້ວຍ "ຄັງເກັບ APK ເວີຊັນເກົ່າ" ເພື່ອບັນທຶກເຂົ້າຄັງທັນທີ.

🛡️ ວິທີປ້ອງກັນບໍ່ໃຫ້ໂທລະສັບອັບເດດແອັບເອງ
ສາເຫດທີ່ແອັບເຊີບເວີເກົ່າໃນໂທລະສັບມັກອັບເດດເປັນເວີຊັນໃໝ່ເອງ ແມ່ນຍ້ອນ Google Play Store ເປີດໂໝດອັບເດດອັດຕະໂນມັດໄວ້. ກະລຸນາເຮັດຕາມ 3 ຂັ້ນຕອນລຸ່ມນີ້ເພື່ອລັອກເວີຊັນເກົ່າໄວ້ຖາວອນ:
1

ປິດອັບເດດອັດຕະໂນມັດສະເພາະແອັບ

ໃນໜ້າ ຄັງແອັບເກົ່າ ໃຫ້ກົດປຸ່ມ "🛡️ ບລັອກອັບເດດ Play Store" ຢູ່ກ້ອງຊື່ແອັບ -> ແລ້ວກົດຈຸດສາມຈຸດ (⋮) อยู່ມຸມຂວາເທິງຂອງ Play Store -> ຕິ๊กອອກ (Uncheck) "ອັບເດດອັດຕະໂນມັດ (Enable auto update)".

2

ປິດການອັບເດດອັດຕະໂນມັດທັງໝົດໃນ Play Store

ເປີດແອັບ Play Store -> ກົດຮູບໂປຣໄຟລ໌ມຸມຂວາເທິງ -> ການຕັ້ງຄ່າ (Settings) -> ຄວາມມັກເຄືອຂ່າຍ (Network preferences) -> ອັບເດດແອັບອັດຕະໂນມັດ (Auto-update apps) -> ເລືອກ "ຢ່າອັບເດດແອັບອັດຕະໂນມັດ (Don't auto-update apps)".
